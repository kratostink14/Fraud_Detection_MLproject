# Fraud Detection System (PaySim Analysis)

Система машинного обучения для автоматического выявления мошеннических транзакций. Проект разработан как демонстрация навыков в области **Exploratory Data Analysis (EDA)**, **Feature Engineering** и построения высокоточных классификаторов на базе **XGBoost**.



## Ключевые аналитические решения

Проект построен на синтетическом датасете PaySim, где основной сложностью является сильный дисбаланс классов (мошенничество составляет < 0.1% данных).

### Инженерия признаков (Feature Engineering)
В ходе анализа были выделены критические аномалии, на которых сфокусирована модель:
* **Error Balance**: Созданы признаки `errorBalanceOrig` и `errorBalanceDest`, выявляющие математические расхождения в балансах счетов после транзакции. Эти признаки стали ключевыми предикторами.
* **Transaction Profiling**: Оптимизация типов данных и фильтрация типов транзакций (`TRANSFER`, `CASH_OUT`), через которые проходят 100% махинаций.

### Оптимизация бизнес-логики
Для минимизации ложных блокировок честных пользователей был произведен переход от стандартного порога классификации (0.5) к **кастомному порогу 0.7**. Это позволило достичь баланса между безопасностью системы и комфортом клиентов.



## Результаты визуализации

Проект включает детальные отчеты, сохраненные в папке `plots/`:
* **Confusion Matrix**: Наглядная оценка False Positives и False Negatives.
* **Precision-Recall Curve**: Обоснование выбора порога 0.7.
* **SHAP / Feature Importance**: Интерпретация вклада каждого признака в итоговое решение модели.



## Технологический стек
* **Data Handling**: `Pandas`, `NumPy`
* **Visualization**: `Matplotlib`, `Seaborn`
* **Machine Learning**: `XGBoost`, `Scikit-learn`
* **Model Interpretation**: `SHAP`
* **Serialization**: `Joblib` (упаковка модели, признаков и метаданных в единый пакет `full_fraud_package.pkl`)
